# SUIRO

水辺の静けさに着想した架空のスキンケアブランド。コピーは「日々に、澄んだひとしずく。」。水色 #E4EFF0、青灰 #254A52、白 #FBFBF7。光と素材の透明感、大きな写真と余白を軸にした5ページ構成。

## ページ

- index.html: ブランド導入、コレクション、質感、読みもの
- products.html: 製品一覧と種類別の絞り込み
- product.html: 化粧水・美容液・クリームを選べる製品詳細
- brand.html: ブランドストーリーと3つの考え方
- journal.html: 朝と夜の短い生活提案2編

化粧水150mL / ¥2,860、美容液30mL / ¥3,960、クリーム50g / ¥3,300。すべて税込参考価格。香りは「水音 — 青い葉とやわらかなウッド」。製品・価格は架空のコンセプト。医学的効能、試験、認証、レビュー、ランキングは設定していない。

## 編集とデモ

編集可能な静的HTML、styles.css、app.js。外部ライブラリとビルド不要。すべて相対パス。製品詳細はクエリitem=toner / serum / creamで直接開ける。

購入デモは数量と参考合計の確認画面で終了する。個人情報欄、form、注文送信、決済、解析、cookieや選択情報の保存処理なし。

## 画像と権利

画像は架空のブランドや製品を表現したイメージです。第三者の写真・コピーは転用していません。元画像と権利記録は納品アーカイブに同梱。
